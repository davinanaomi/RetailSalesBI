# RetailBI – Retail Sales Intelligence Dashboard

## Deskripsi
RetailBI merupakan dashboard Business Intelligence untuk membantu menganalisis performa penjualan pada dataset retail. Dashboard menampilkan informasi penjualan, keuntungan, jumlah pesanan, performa kategori, dan produk.

## Fitur Dashboard
- Total Sales
- Total Profit
- Total Orders
- Total Products
- Filter berdasarkan tahun dan kategori
- Grafik tren penjualan bulanan
- Grafik penjualan berdasarkan kategori
- Business Insights berdasarkan data
- Tabel Top 10 Products berdasarkan penjualan

## Teknologi yang Digunakan
- HTML, CSS, dan JavaScript
- Vite sebagai development dan build tool
- Chart.js untuk visualisasi grafik
- SheetJS (xlsx) untuk membaca dataset Excel
- ChatGPT (GPT-6) sebagai AI assistant untuk membantu proses perancangan dan penulisan kode

## Dataset
Dataset yang digunakan: `Superstore.xlsx`

File dataset disimpan di:
`public/data/Superstore.xlsx`

## Cara Menjalankan Project
1. Pastikan Node.js sudah terinstal.
2. Buka folder project melalui VS Code.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat lokal yang muncul di terminal.

## Build Production
Jalankan perintah `npm run build`.

Hasil build akan tersimpan di folder `dist`.
